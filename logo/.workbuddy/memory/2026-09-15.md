## 第十六轮（根因·定论）：Tauri 取 ICO 第 0 条目当窗口图标 → 16px 被放大 → 糊

- 用户明确：原版 3D 也糊，**就要扁平版**；核心疑惑"为什么 `32x32.png` 文件清晰、用上系统却糊"。
- **真凶（读 Tauri 源码实证）**：`tauri-codegen-2.6.2/src/image.rs` 的 `new_ico()`：
  ```rust
  let entry = &icon_dir.entries()[0];   // 只取 ICO 第 0 个条目
  let rgba = entry.decode()...;         // 解码成单一尺寸位图当窗口图标
  IconFormat::Image { width: entry.width(), height: entry.height() }
  ```
  → Windows 上 Tauri 用 **ICO 文件里的第 0 帧**作窗口图标，且**只有这一种尺寸**；任务栏再按自己需要的尺寸缩放它。我们 ICO 一直按**升序**写 → 第 0 帧 = **16×16** → 任务栏（150% 下 36px）把 16px **放大约 2.3×** → 一团糊。而 `32x32.png` 是 1:1 查看 → 清晰。**这解释了"文件清晰、系统糊"的全部现象**，也解释了为何 logo 一直糊。
- 实证锐度：修复前 16→36 放大 = 4858.8；修复后 256→36 缩小 = 6024.3；参考 `32x32.png` = 6144.1。（对比图 `fix_before_after.png`，中间就是用户看到的"一团糊"。）
- **修复**：重写 `src-tauri/icons/icon.ico`，帧顺序改为 **`[256,128,96,80,72,64,56,48,42,40,36,32,30,28,24,20,16]`**（256 置首位），并覆盖 100–200% DPI 的常见尺寸。**只改 icon.ico，美术完全不变**（仍为 `favicon.svg` 扁平版）。`32x32.png` 等 PNG 未动。
