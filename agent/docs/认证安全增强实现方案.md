# 认证安全增强实现方案

## 概述

本文档详细说明了针对 gnome-remote-agent 认证系统的安全增强措施，包括：
1. 认证失败次数限制（防暴力破解）
2. IP速率限制（防DoS攻击）
3. 会话超时机制
4. 认证挑战定期清理

---

## 一、已实现的安全模块

### 1.1 认证速率限制器 (`rate_limiter.rs`)

#### 核心功能
- **失败次数限制**：每个用户名最多5次失败，锁定15分钟
- **IP速率限制**：每个IP每分钟最多10次认证请求
- **自动清理**：定期清理过期记录，防止内存泄漏

#### 关键代码

```rust
// 检查用户名是否被锁定（暴力破解防护）
pub async fn is_username_allowed(&self, username: &str) -> Result<bool>

// 检查IP是否超过速率限制（DoS防护）
pub async fn is_ip_allowed(&self, client_ip: &str) -> Result<bool>

// 记录认证失败
pub async fn record_failure(&self, username: &str)

// 清除失败记录（认证成功后）
pub async fn clear_failures(&self, username: &str)
```

### 1.2 会话超时机制 (`session.rs`)

#### 核心功能
- **会话超时**：24小时无活动自动过期
- **活动追踪**：每次用户操作更新 `last_activity` 时间戳
- **剩余时间查询**：可查询会话剩余有效时间

#### 关键代码

```rust
// 检查会话是否已过期
pub fn is_expired(&self) -> bool

// 更新最后活动时间（心跳）
pub fn touch(&mut self)

// 获取剩余有效时间
pub fn remaining_time(&self) -> Option<Duration>
```

### 2.2 在认证流程中集成速率限制

**文件**: `src/server/quic.rs`

**修改位置**: `async fn handle_connection()`

#### 2.2.1 密码认证流程

```rust
Payload::AuthPasswordRequest { username, password } => {
    tracing::info!("收到密码认证请求: remote={}, username={}", remote, username);

    // ========== 新增：速率限制检查 ==========

    // 1. 检查IP是否超过速率限制
    if !rate_limiter.is_ip_allowed(&remote.ip().to_string()).await? {
        audit_log.log_auth_failure(username, 0, "ip_rate_limited");
        send_auth_response(&mut auth_send, auth_envelope.request_id, false,
            Some("请求过于频繁，请稍后再试"), None).await?;
        connection.close(0u32.into(), b"rate limited");
        return Ok(());
    }

    // 2. 检查用户名是否被锁定
    if !rate_limiter.is_username_allowed(username).await? {
        audit_log.log_auth_failure(username, 0, "account_locked");
        send_auth_response(&mut auth_send, auth_envelope.request_id, false,
            Some("账户已锁定，请15分钟后再试"), None).await?;
        connection.close(0u32.into(), b"account locked");
        return Ok(());
    }

    // ========== 原有认证逻辑 ==========

    match authenticator.authenticate_password(username, password) {
        Ok(crate::auth::AuthResult::Success(identity)) => {
            // ✅ 认证成功：清除失败记录
            rate_limiter.clear_failures(username).await;

            let session = UserSession::new(identity);
            ctx.set_session(session.clone()).await;
            audit_log.log_auth_success(&session.username, session.uid, "password");
            send_auth_response(&mut auth_send, auth_envelope.request_id, true, None, Some(&session.session_id)).await?;
            tracing::info!("✅ 密码认证成功: remote={}, user={}", remote, session.username);
            session
        }
        Ok(crate::auth::AuthResult::Failure) => {
            // ❌ 认证失败：记录失败次数
            rate_limiter.record_failure(username).await;

            audit_log.log_auth_failure(username, 0, "invalid_password");
            send_auth_response(&mut auth_send, auth_envelope.request_id, false,
                Some("用户名或密码错误"), None).await?;
            connection.close(0u32.into(), b"auth failed");
            return Ok(());
        }
        Err(e) => {
            // ❌ 认证错误：记录失败次数
            rate_limiter.record_failure(username).await;

            tracing::error!("密码认证异常: {}", e);
            audit_log.log_auth_failure(username, 0, "auth_error");
            send_auth_response(&mut auth_send, auth_envelope.request_id, false,
                Some("认证服务异常"), None).await?;
            connection.close(0u32.into(), b"auth error");
            return Ok(());
        }
    }
}
```

## 三、认证过期处理机制详解

### 3.1 过期场景分类

#### 场景1：会话超时（Session Timeout）

**触发条件**：
- 用户24小时无任何操作
- 会话的 `last_activity` 时间戳超过阈值

**处理流程**：
```rust
// 每次用户操作时调用
pub async fn handle_user_action(session: &mut UserSession) -> Result<()> {
    // 1. 检查会话是否过期
    if session.is_expired() {
        tracing::warn!(
            "会话已过期: session_id={}, last_activity={:?}",
            session.session_id,
            session.last_activity
        );
        return Err(anyhow!("会话已过期，请重新登录"));
    }

    // 2. 更新活动时间（心跳）
    session.touch();

    // 3. 记录审计日志
    tracing::debug!(
        "会话活动更新: session_id={}, remaining={:?}",
        session.session_id,
        session.remaining_time()
    );

    Ok(())
}
```

**客户端处理**：
```typescript
// 客户端收到会话过期响应后
if (error.code === 'SESSION_EXPIRED') {
    // 1. 清除本地会话缓存
    localStorage.removeItem('session_id');

    // 2. 断开连接
    connection.close();

    // 3. 跳转到登录页
    router.push('/login?reason=session_expired');
}
```

#### 场景2：挑战过期（Challenge Expiration）

**触发条件**：
- 公钥认证的挑战生成后超过60秒
- 挑战未在有效期内被签名响应

**处理流程**：
```rust
// 定期清理任务（每5分钟）
tokio::spawn(async move {
    let mut interval = tokio::time::interval(Duration::from_secs(300));
    loop {
        interval.tick().await;
        challenge_manager.cleanup_expired().await;
        tracing::debug!("挑战缓存清理完成");
    }
});

// 认证时检查
if challenge.is_expired() {
    tracing::warn!(
        "挑战已过期: challenge_id={}, expired_at={:?}",
        challenge_id,
        challenge.expires_at
    );
    return Err(anyhow!("认证挑战已过期，请重新发起认证"));
}
```

#### 场景3：账户锁定（Account Lockout）

**触发条件**：
- 同一用户名连续失败5次认证
- 锁定时长15分钟

**处理流程**：
```rust
// 检查是否被锁定
if !rate_limiter.is_username_allowed(username).await? {
    let stats = rate_limiter.get_stats().await;
    tracing::warn!(
        "账户被锁定: username={}, failed_attempts={}, locked_accounts={}",
        username,
        stats.total_failed_attempts,
        stats.locked_accounts
    );

    // 返回友好提示（不泄露失败次数）
    return Err(anyhow!("账户已锁定，请15分钟后再试"));
}
```

**解锁机制**：
```rust
// 方式1：自动解锁（15分钟后）
// rate_limiter.cleanup_expired() 会自动清理过期锁定

// 方式2：手动解锁（管理员）
pub async fn admin_unlock_account(username: &str) -> Result<()> {
    rate_limiter.clear_failures(username).await;
    tracing::info!("管理员解锁账户: username={}", username);
    Ok(())
}

// 方式3：认证成功解锁
// 认证成功时自动调用 rate_limiter.clear_failures(username)
```

## 四、定期清理任务

### 4.1 清理任务配置

| 清理项 | 清理周期 | 过期阈值 | 说明 |
|--------|---------|---------|------|
| 失败次数记录 | 5分钟 | 1小时无活动 | 清理过期的锁定记录 |
| IP请求记录 | 5分钟 | 10分钟无活动 | 清理无活动的IP记录 |
| 认证挑战 | 5分钟 | 60秒过期 | 清理未完成的挑战 |
| 传输会话 | 按需 | 连接关闭时 | 清理未完成的上传 |

### 4.2 清理任务实现

```rust
// 主函数中启动清理任务
tokio::spawn(async move {
    let mut interval = tokio::time::interval(Duration::from_secs(300)); // 5分钟

    loop {
        interval.tick().await;

        // 1. 清理速率限制器
        rate_limiter.cleanup_expired().await;

        // 2. 清理挑战缓存
        challenge_manager.cleanup_expired().await;

        // 3. 清理传输会话
        crate::handler::cleanup_expired_transfer_sessions().await;

        tracing::debug!("定期清理任务完成");
    }
});
```
