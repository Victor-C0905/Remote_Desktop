## 四、验证方法修正（重要）

- `pgrep -f 'sleep N'` 会自匹配承载探针命令的 bash（命令行内嵌模式串），**产生假阳性孤儿报告**；
  正确姿势：`pgrep -x sleep` 或 `ps + grep -v grep`。第五/六轮的孤儿结论据此修正：
  R6 的孤儿（单 bash kill 时代）为真，本轮修复后已清零。
- evaljs 返回 Promise 的输出偶发丢失；offsetParent 对 position:fixed 元素恒为 null，
  不能用作可见性判据。
- 侧边栏可见性/焦点断言建议一律截图兜底。
