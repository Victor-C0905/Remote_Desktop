## 一、目标与范围

1. 验证第一/二轮 13 项修复无回归（终端搜索、编辑器 mtime/统计、servers.bin 写盘、

4. 产出按 P1/P2/P3 排序的缺陷清单与证据，能直接转修复任务。

范围：Shell（TopBar/Dock/桌面/总览/通知/壁纸）、Terminal、FileManager、TextEditor、
Image/Hex/PDF/Archive 查看器、Browser、SystemMonitor、Settings、ServerManager、
传输、通知、窗口系统、存储与本地数据。

不在本轮：协议/agent 内部实现审计（已有安全审计基线）、发版流程、跨平台（仅 Windows 客户端）。

### 5.3 伪影排除协议（沿用第二轮教训）

1. 状态判定只用 `data-maximized` / `data-snap-zone` / DOM/管理器状态，**不用静态
   按钮 title**。
2. 交互测试前先用 Win32 枚举确认主窗口在屏内；OS 合成拖拽不得落在顶栏。
3. HMR 重载会丢 `WindowManagerContext`（dev 已知现象），统一用 `location.reload()`。
4. 坐标系不互相换算：Win32 物理像素 / CopyFromScreen / CDP CSS px 各自独立，
   定位一律以 DOM gBCR 为准。
