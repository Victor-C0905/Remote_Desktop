# Quirel 客户端第十一轮测试计划：UI 交互与体验专项（2026-11-15）

- 被测：`fix/file-manager-sidebar` @ 工作树（前十轮修复全量 + vite 实时前端）
- 定位：**探索性**——不针对已知缺陷回归，而是以普通用户视角扫交互流程，
  找「能用但别扭」「误导」「缺反馈」类体验问题（含小缺陷）
- 环境：沿用第十轮（vite:1420 / quireld:8443 含实例锁 / 客户端 CDP:9223）

## 探针清单

| # | 面 | 探针 |
|---|---|---|
| P1 | 通知中心 | badge 计数口径/陈旧性；开面板、标记已读、清空交互；通知点击行为 |
| P2 | 服务器编辑对话框 | 空名/空主机/越界端口校验反馈；取消/× 关闭是否丢改动有提示；编辑中字段焦点 |
| P3 | FM 地址栏 | 点击进入编辑态（是否全选/光标）；Enter 无效路径反馈；Esc 退出编辑；失焦行为 |
| P4 | FM 搜索 | 搜索态切目录/换服；清空按钮；搜索高亮与状态栏口径 |
| P5 | FM 空目录/右键 | 空目录右键菜单项合理性；粘贴空剪贴板行为 |
| P6 | 终端 | 页签开关与标题序号；搜索 UI 开合/Esc；演示模式入口文案 |
| P7 | 窗口 | 双击标题栏最大化；贴边吸附触发与退出；Esc 关窗范围 |
| P8 | 断连态体验 | 断连时各应用（FM/终端/传输条）的占位与按钮可用性 |
| P9 | 通知时效 | 断连/重连/解压完成等事件的 toast 与中心口径一致性 |
