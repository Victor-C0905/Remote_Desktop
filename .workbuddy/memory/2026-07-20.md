### 规模判定（代码量维度）: 中型项目
### 规模判定（功能复杂度维度）: 中大型项目

### 核心功能域
1. **QUIC 传输层** - 自定义 Envelope 协议(40+消息类型), 多路复用 Stream, 心跳 Watchdog(2s+3s双重保障)
2. **远程文件系统** - 完整CRUD + apply_diff 行级差异同步(流量优化) + 分块传输(进度/速度/ETA/取消)
3. **远程终端** - 持久双向 Stream 隧道, 跨平台 PTY(Windows ConPTY + Unix PTY)
4. **桌面窗口系统** - 自研 22 模块(WindowManager/布局引擎/事件总线/序列化持久化)
5. **实时订阅** - 5类(metrics/file_changes/process_events/app_logs/service_status)
6. **桌面应用套件** - 文件管理器/终端(xterm)/系统监控/文本编辑器(含Hex编辑+diff)/设置
7. **桌面外壳** - Desktop/TopBar/NotificationCenter + 壁纸/主题系统

### 技术栈
- 前端: React 19 + TypeScript + zustand + xterm.js + html2canvas + chroma-js
- 后端: Rust + Tauri 2 + quinn(QUIC) + rustls + tokio
- 测试: vitest + testing-library

### 关键发现
- 项目本质是一个"基于QUIC的远程桌面管理环境"，非简单远程工具
- 自研窗口管理系统是最大复杂度来源(通常依赖第三方库)
- 单人项目达到此功能深度属于高复杂度
